# ☕ Black Coffee Management System — Server

The backend API for **Black Coffee Management System**, a centralized platform designed to manage coffee shop operations efficiently.

This project aims to simplify daily coffee shop management, including inventory, products, sales, and staff operations.

## 🚀 Project Overview

Black Coffee Management System is being developed to provide a structured and scalable management solution for coffee shop businesses.

The server handles API requests, business logic, database operations, and communication with the client application.

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Backend Framework:** Express.js
- **Database:** MongoDB
- **API Architecture:** REST API
- **Language:** JavaScript

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/sabermahmud/black-coffee-management-system-server.git
```

### 2. Navigate to the project directory

```bash
cd black-coffee-management-system-server
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

### 5. Start the development server

```bash
npm run dev
```

## 🔐 Environment Variables

| Variable | Description |
|---|---|
| `PORT` | Server port |
| `MONGODB_URI` | MongoDB connection string |
